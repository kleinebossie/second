# Second v1.0.0 Release Notes (Soft Release)

Second is an open-source local AI chess coach based on Qwen 3.5.
This `v1.0.0` release ships **Second-1.0-2B** and the Lichess browser extension.

## What Is Included

- **Model (`Second-1.0-2B`):** Trained with Stage T2 engine-grounded distillation (`SFT-A1`) and token-level DAPO RL (`RL-B2`, Reward v2).
  - Weights (`bfloat16` merged + LoRA): `joebos/Second-1.0-2B` on Hugging Face.
  - Quantized browser shards (`Q4_K_M`, ~1.2 GB total): `joebos/Second-1.0-2B-GGUF` on Hugging Face.
- **Browser Extension (`second-extension-v1.0.0.zip`):** Manifest V3 side panel extension for Google Chrome and Microsoft Edge on `lichess.org`.
  - Runs `Second-1.0-2B` locally via `wllama` WebAssembly.
  - Uses local Stockfish WebAssembly and optional polite Lichess Cloud Eval.
  - Enforces a fail-closed fair-play lock on live games and puzzles.
  - Exports local thumbs-up and thumbs-down ratings as JSON for `v1.1` training.
- **Demo Space (`demo_space/`):** Gradio application where users can paste a PGN or FEN, pick a move, and read an explanation.

## Benchmark Summary (`eval/testset-1.0.jsonl`, 300 Items)

- **Hard-Fail Rate (9 rule checks):** `4.67%` (`14 / 300`; `4.00%` after `Q4_K_M` quantization on 100 stratified items)
- **Target Length Compliance:** `99.67%` (`62.0` words mean)
- **First-Person Diary Voice Rate:** `0.00%`
- **Better-Move Counterfactual Score:** `1.0000`
- **Debiased Gemini Judge Overall:** `3.96 / 5.0`
- **Pairwise Decisive Win Rates:** `281W–0L` (`100.0%`) vs `grpo-1.0-2b` v1, `293W–0L` (`100.0%`) vs `base-qwen-2b`, and `202W–20L` (`91.0%`) vs `gemini-flash`.

## Known Limits in v1.0.0

- `Second-1.0-2B` ships in **Fast** mode only.
- `0.8B`, `4B`, and `9B` sizes are deferred to `v1.1` after planned fact-extractor upgrades.
- Subtle positional moves without concrete tactics can receive shallow explanations. Exported user ratings from this preview release will train `v1.1`.
